# Pre-wedding video (optional)

Put an MP4 here (H.264, 1080p or 720p) and set `media.video` in
`assets/js/config.js` to its path, e.g. `"assets/video/prewedding.mp4"`.

GitHub has a 100 MB per-file limit, and large videos are slow on mobile data.
For anything over ~25 MB, upload to YouTube or Vimeo instead and link it.

Leave `media.video` as `""` to hide the video section entirely.
