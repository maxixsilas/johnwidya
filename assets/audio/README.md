# Background music

Put one file here named `music.mp3` (or update the filename in
`assets/js/config.js` → `media.music`).

- Format: MP3, 128 kbps mono or stereo
- Length: 2–4 minutes is plenty — the track loops automatically
- Target size: under 3 MB

Use music you have the right to use. Royalty-free sources: Pixabay Music,
YouTube Audio Library, Uppbeat.

To turn music off completely, set `media.music` to `""` in config.js —
the floating button then disappears.
